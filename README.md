# Анализатор качества базы данных

Анализатор схем PostgreSQL помогает бэкенд-разработчикам проверять миграции перед релизом, а администраторам баз данных — находить риски в незнакомой схеме.

## Состояние проекта

В ветке `dev` доступны описание продукта, план и требования. Реализация CLI запланирована. Поддерживаемую версию PostgreSQL и минимальные права для подключения уточнят на прототипе.

## Быстрый старт

Для клонирования по SSH нужен доступ к репозиторию на GitHub.

1. Клонируйте ветку проекта.

   ```sh
   git clone --branch dev git@github.com:kolomigor/database-analyzer.git
   ```

2. Перейдите в каталог проекта.

   ```sh
   cd database-analyzer
   ```

3. Откройте раздел «Функциональные требования» в спецификации. [SRS](requirements/SRS.docx)

## Что входит в MVP

- Аудит схемы PostgreSQL в режиме чтения. Один запуск работает с одной базой.
- Проверки первичных и внешних ключей, типов данных, допустимости `NULL` и индексов. При достаточной статистике анализатор выделяет таблицы и индексы, которые стоит проверить на рабочей нагрузке.
- HTML-отчёт с общей оценкой, уровнем серьёзности и рекомендацией по каждой находке. Экспорт JSON для автоматизации.

## Пример ожидаемого результата

В тестовой схеме у таблицы `public.audit_example` нет первичного ключа. По сценарию `TC-05` в отчёте ожидается ошибка с таким обоснованием и рекомендацией. [RTM](requirements/RTM.docx)

| Объект | Серьёзность | Обоснование | Рекомендация |
| --- | --- | --- | --- |
| `public.audit_example` | Ошибка | У таблицы нет первичного ключа | Определить, какие столбцы однозначно идентифицируют строку, и проверить возможность добавить первичный ключ |

Если это единственная находка, ожидаемая оценка качества равна 90 из 100. [SRS](requirements/SRS.docx)
